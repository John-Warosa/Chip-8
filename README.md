# Chip-8

This is version 2 of an Emulator for the Chip-8 instruction set I am writing.
Since the previous version was functional, I decided to clean up the code and user experience.

## (Upcoming) Changes

The core functionalityof the emulator will mostly stay unchanged.
The core changes I aim for are:

- make code cleaner and less disorganised
- improve visual interface of the emulator
- Add a switch to toggle quirks on or off
- Add a memory viewer
- Add the possibility to pause and reload the emulator

## Test ROMs

I am still including the Test ROMs of Timendus to test the functionality (https://github.com/Timendus/chip8-test-suite).
More game ROMs will be added to the Repo to test (and perhaps enjoy) the emulator.

## Current state

After refactoring, the emulator is functional again. The emulator now also supports restarting by pressing Cmd + r (on Mac)
